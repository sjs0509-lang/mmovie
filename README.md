# POSTER CINEMA

영화 포스터의 국가별 색채와 구성을 탐색하는 정적 웹사이트입니다.

## 실행하기

`index.html`을 브라우저에서 열면 됩니다. 별도의 설치나 빌드 과정은 필요하지 않습니다. 로컬 서버를 사용하려면 이 폴더에서 아래 명령을 실행하고 브라우저로 표시된 주소에 접속하세요.

```bash
python3 -m http.server 8000
```

## 파일 구성

- `index.html` — 페이지 구조와 콘텐츠
- `style.css` — 디자인, 반응형 레이아웃과 애니메이션
- `app.js` — 영화 선택, 시각화, 검색과 인터랙션
- `data.js` — 영화·포스터·색채 비교 데이터
- `images/` — 화면에 사용하는 포스터 이미지
- `fonts/` — Bebas Neue와 고운돋움 글꼴 파일

영화와 색상 데이터를 변경하려면 `data.js`를, 페이지의 문구와 구성을 바꾸려면 `index.html`을 수정하세요. 포스터 이미지는 MoviePosterDB에서 수집했으며, 이미지 권리는 각 권리자에게 있습니다.
